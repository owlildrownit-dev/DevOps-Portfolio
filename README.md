# Red Light Detector

Система детекции проезда на красный свет светофора.  
Анализирует фото и видео, фиксирует нарушения, формирует отчёты PDF и Excel.

Автор: Кривошеин Даниил Романович, группа УБВТ2401, МТУСИ.  
Тема практики №16 — Детекция автомобилей на красном сигнале светофора.

**Стек:** Python · FastAPI · YOLOv8n (ONNX Runtime) · OpenCV · pywebview

---

## Требования

- **Python 3.11 или новее** (проверено на 3.11–3.14)
- pip (входит в стандартную установку Python)
- Интернет для первичной установки зависимостей

```cmd
cd C:\путь\к\папке\практика
pip install -r requirements.txt
```

Зависимости занимают около 400 МБ. Модель YOLOv8n уже лежит в `models/yolov8n.onnx` — скачивать ничего не нужно.

## Запуск

### Вариант 1 — веб-приложение в браузере (рекомендуется)

Двойной клик на `run.bat` **или** команда в терминале:

```cmd
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

Затем открыть в браузере: **http://localhost:8000**

Флаг `--reload` включает автоматическую перезагрузку при изменении кода. Для продакшена уберите его.

### Вариант 2 — десктоп-окно (pywebview)

```cmd
python desktop.py
```

Запускает FastAPI-сервер на случайном свободном порту и открывает нативное окно приложения. Браузер не нужен.

## Использование

1. **Загрузите файл** — перетащите фото или видео на зону загрузки, или нажмите на неё.  
   Поддерживаемые форматы: JPG, PNG, WEBP, MP4, AVI, MOV, MKV, WEBM. До 500 МБ.

2. **Выберите режим стоп-линии:**
   - *Автоопределение* — алгоритм находит линию по краям на изображении (Canny + Hough)
   - *Автоматически (с резервной)* — если линия по краям не найдена, подставляется горизонталь на 65% высоты кадра (срабатывает всегда, в том числе на тёмных/ночных кадрах)
   - *Вручную* — кликните два раза на предпросмотре, чтобы нарисовать линию

3. **Выберите режим светофора:**
   - *Автоопределение* — сначала ищется бокс светофора (YOLO, класс `traffic light`) и цвет определяется внутри него по HSV; если светофор не найден, выполняется резервное сканирование верхних 60% кадра
   - *Принудительно красный / жёлтый / зелёный* — если автоопределение ошибается (актуально для съёмки с дрона/квадрокоптера или сильных засветок уличным освещением)

4. **Нажмите «Анализировать».**

5. **Результат:** статистика (автомобили, нарушения, сигнал, время обработки), обработанное фото/видео с отрисованной стоп-линией и рамками, список событий нарушений с таймкодами, ссылки для скачивания PDF и Excel.
   - Для **фото**: каждый автомобиль за стоп-линией при красном сигнале засчитывается как нарушение, для него сохраняется отдельный кадр-доказательство.
   - Для **видео**: нарушение засчитывается, когда трек автомобиля реально пересекает стоп-линию при красном сигнале (устойчивое сглаживание сигнала светофора окном в 5 кадров) — для каждого события сохраняется кадр момента пересечения.

6. **Отчёты PDF/Excel** содержат таблицу метаданных, таблицу событий и кадры-доказательства нарушений (кириллица корректно отображается через системный шрифт Arial/Times).

7. **История** в нижней части страницы — все предыдущие анализы с экспортом.

## Конфигурация

Скопируйте `.env.example` в `.env` и при необходимости измените:

```env
CONFIDENCE=0.35             # порог уверенности детектора (0–1)
IOU_THRESHOLD=0.45          # порог IoU для NMS
MAX_UPLOAD_MB=500           # максимальный размер загружаемого файла
DEFAULT_STOP_LINE_Y=0.65    # позиция резервной стоп-линии (доля высоты кадра)
TRAFFIC_LIGHT_SMOOTHING=5   # окно сглаживания сигнала светофора на видео (кадров)
```

## Устранение проблем

**`ModuleNotFoundError`** — запустите `pip install -r requirements.txt` ещё раз.

**Видео не читается** — OpenCV автоматически обходит кириллические пути через временную копию. Если ошибка всё равно возникает, скопируйте файл в папку с латинским путём.

**Порт 8000 занят** — измените порт:
```cmd
python -m uvicorn app.main:app --port 8001
```

**Сигнал светофора определён неверно** — HSV-детектор рассчитан на классическую съёмку с дорожной камеры (светофор в кадре сбоку/сверху). На кадрах с квадрокоптера или при сильной засветке уличными фонарями возможны ошибки — используйте принудительный режим сигнала.

**Изменения в коде не применяются в десктоп-режиме** — `desktop.py` запускает `uvicorn` без `--reload`, в отличие от `run.bat`. После правок закройте окно приложения и запустите `python desktop.py` заново.

**Кириллица в PDF выглядит как квадраты** — отчёт использует системный шрифт Windows (`Arial`/`Times New Roman`). На Linux/macOS без этих шрифтов установите `msttcorefonts` или укажите путь к любому TTF-шрифту с кириллицей в `app/services/exports.py`.

**Модель не найдена** — убедитесь, что файл `models/yolov8n.onnx` существует. Если он был удалён, сгенерируйте его заново:
```cmd
pip install ultralytics
python -c "from ultralytics import YOLO; YOLO('yolov8n.pt').export(format='onnx', imgsz=640, opset=17, simplify=True)"
```
Переместите получившийся `yolov8n.onnx` в папку `models/`.
