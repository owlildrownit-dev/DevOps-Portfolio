# Нагрузка CPU PostgreSQL до и после оптимизации

`run.sh` поднимает отдельный кластер PostgreSQL с `pg_stat_statements`, генерирует данные
(200 000 клиентов, 2 000 000 заказов), дает одинаковую нагрузку до и после оптимизации
и строит отчет `results/REPORT.md`.

```bash
./run.sh                    # по умолчанию 5 TPS, 120 с на прогон
RATE=3 DURATION=300 ./run.sh
```

Запускать от обычного пользователя (`initdb` не работает от root).

## Методика

- **Одинаковая нагрузка:** pgbench с фиксированным темпом (`-R`), один и тот же сценарий (`sql/workload.pgbench`).
- **CPU:** процессорное время всех процессов кластера по `/proc/<pid>/stat`
  (postmaster, живые дочерние процессы и завершенные через `cutime`/`cstime`).
- **Тяжелые запросы:** `pg_stat_statements` по `total_exec_time`, планы `EXPLAIN (ANALYZE, BUFFERS)`.
- **Проверка корректности:** если фактический TPS ниже заданного или растет очередь
  (lag > 100 мс), отчет помечает сравнение как некорректное.

## Оптимизация (`sql/02_optimize.sql`)

| Запрос | Проблема | Решение |
| --- | --- | --- |
| История заказов клиента | полное сканирование 2 млн строк + сортировка | индекс `(customer_id, created_at DESC)` |
| Поиск клиента по `lower(email)` | обычный индекс по `email` не применим | индекс по выражению `lower(email)` |

Индексы создаются `CONCURRENTLY`, без блокировки записи.

## Результат (GitHub Codespaces, 28.10.2026)

| Прогон | TPS до / после | Lag до | CPU до | CPU после | Вердикт |
| --- | --- | --- | --- | --- | --- |
| 1, RATE=5 | 4,92 / 5,12 | 654 мс | 191,75 с | 0,58 с | некорректно: очередь |
| 1, RATE=3 | 3,03 / 3,19 | 23 мс | 118,30 с | 0,39 с | нагрузка сопоставима |
| 2, RATE=3 ([`results/REPORT.md`](results/REPORT.md)) | 3,20 / 3,01 | 53 мс | 125,09 с | 0,43 с | нагрузка сопоставима |

Снижение во втором прогоне: (125,09 − 0,43) / 125,09 × 100 ≈ 99,7%; на одну транзакцию 99,6%.
Отчет второго прогона построен предыдущей версией скрипта (`run_lab.sh`, до переименования в `run.sh`).
На стенде почти вся нагрузка приходится на два неоптимальных запроса, поэтому эффект близок к 100%.
